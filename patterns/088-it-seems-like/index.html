짧은 문장에 살을 붙여가는 꼬리물기 방식으로 자신의 실력에 맞게 단계별로 학습하세요.

짧게 말하기 · 초급 + 확장해서 말하기 · 중급 + 더 추가해서 말하기 · 고급

본문 하단의 동영상 강의를 활용하시면 학습 효과가 훨씬 높아집니다.

패턴 088

It seems like

"~인 것 같아요"
영상 강의
클릭
또는
스캔
Grammar Point
'It seems like + 주어 + 동사' 형태로, 확실하지 않은 상황이나 인상을 부드럽게 표현할 때 사용해요.
seem은 외부 단서를 바탕으로 한 추측을 나타내며, 직접적인 단정을 피하는 공손한 뉘앙스를 가져요.
'It seems like + 명사구' 형태로도 쓸 수 있어요.
#
짧게 말하기(초급)  +  확장해서 말하기(중급)  +  더 추가해서 말하기(고급)
01
It seems like it's going to rain.
비가 올 것 같네요.
It seems like it's going to rain. I came out without my umbrella.
비가 올 것 같네요. 우산 없이 나왔거든요.
It seems like it's going to rain. I came out without my umbrella, so I should get home quickly.
비가 올 것 같네요. 우산 없이 나왔거든요. 빨리 집에 가야겠어요.
without ~없이 quickly 빨리
02
It seems like there is a problem.
문제가 있는 것 같아요.
It seems like there is a problem with the wifi.
와이파이에 문제가 있는 것 같아요.
It seems like there is a problem with the wifi, so I cannot connect to the internet.
와이파이에 문제가 있는 것 같아서 인터넷에 연결할 수가 없어요.
connect to ~에 연결하다 wifi 와이파이
03
It seems like he's a good person.
그는 좋은 사람인 것 같아요.
It seems like he's a good person who always helps other people.
그는 항상 다른 사람들을 돕는 좋은 사람인 것 같아요.
It seems like he's a good person who always helps other people even when he's busy.
그는 항상 다른 사람들을 돕는 좋은 사람인 것 같아요. 심지어 바쁠 때도요.
even when 심지어 ~할 때도 always 항상
04
It seems like we're lost.
우리 길 잃은 것 같아요.
It seems like we're lost in the mall parking lot.
쇼핑몰 주차장에서 우리 길 잃은 것 같아요.
It seems like we're lost in the mall parking lot because we can't remember where we parked.
쇼핑몰 주차장에서 우리 길 잃은 것 같은데, 차를 어디에 세웠는지 기억이 안 나요.
remember 기억하다 parking lot 주차장
05
It seems like you misunderstood.
제 말을 잘못 이해하신 것 같아요.
It seems like you misunderstood what I said.
제가 말씀드린 내용을 잘못 이해하신 것 같아요.
It seems like you misunderstood what I said on the phone.
전화로 제가 말씀드린 내용을 잘못 이해하신 것 같아요.
misunderstand 잘못 이해하다 on the phone 전화로

06
It seems like it'll take some time.
시간이 좀 걸릴 것 같아요.
It seems like it'll take some time to fully recover.
완전히 회복하는 데 시간이 좀 걸릴 것 같아요.
It seems like it'll take some time to fully recover after my knee surgery.
무릎 수술 후에 완전히 회복하는 데 시간이 좀 걸릴 것 같아요.
fully 완전히 recover 회복하다
07
It seems like a dream.
꿈 같아요.
It seems like a dream that I got promoted.
제가 승진한 게 꿈 같아요.
It seems like a dream that I got promoted this fast.
제가 이렇게 빨리 승진한 게 꿈 같아요.
get promoted 승진하다 this fast 이렇게 빨리
08
It seems like she is happy.
그녀는 행복해 보여요.
It seems like she is happy these days.
그녀는 요즘 행복해 보여요.
It seems like she is happy these days since she finally moved to her new apartment.
그녀는 요즘 행복해 보이는데, 드디어 새 아파트로 이사했거든요.
since ~이기 때문에 finally 드디어
09
It seems like no one is here.
아무도 여기 없는 것 같네요.
It seems like no one is here at this time usually.
이 시간에는 보통 아무도 여기 없는 것 같아요.
It seems like no one is here at this time usually because it's lunch time.
점심시간이라서 이 시간에는 보통 아무도 여기 없는 것 같아요.
usually 보통 because ~이기 때문에
10
It seems like it's over.
끝난 것 같아요.
It seems like it's over between them.
그들 사이가 끝난 것 같아요.
It seems like it's over between them since they keep fighting.
그들이 계속 싸우는 걸 보니 그들 사이가 끝난 것 같아요.
since ~이기 때문에 keep ~ing 계속 ~하다
