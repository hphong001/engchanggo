I know how to

"~하는 법을 알아요"
영상 강의
클릭
또는
스캔
Grammar Point
'I know how to + 동사원형'은 특정 행동을 수행하는 방법이나 능력을 알고 있다는 것을 표현하는 패턴이에요.
'how to'는 '~하는 방법'을 의미하며, 뒤에 반드시 동사원형이 와야 해요.
단순한 가능 여부를 넘어 구체적인 방법을 알고 있음을 강조할 때 자주 사용해요.
#
짧게 말하기(초급)  +  확장해서 말하기(중급)  +  더 추가해서 말하기(고급)
01
I know how to swim.
나는 수영할 줄 알아요.
I know how to swim in the ocean.
저는 바다에서 수영할 줄 알아요.
I know how to swim in the ocean, so I can teach you this summer.
저는 바다에서 수영할 줄 알아요, 그래서 이번 여름에 가르쳐 줄 수 있어요.
in the ocean 바다에서 so (결과) 그래서
02
I know how to make a reservation.
나는 예약하는 방법 알아요.
I know how to make a reservation online.
나는 온라인으로 예약하는 방법 알아요.
I know how to make a reservation online because I do it often.
나는 온라인으로 예약하는 방법 알아요. 자주 하거든요.
make a reservation 예약하다 because ~때문에
03
I know how to cook.
저는 요리하는 방법을 알아요.
I know how to cook Korean food.
저는 한국 음식을 요리하는 방법을 알아요.
I know how to cook Korean food that my friends like.
저는 친구들이 좋아하는 한국 음식을 요리하는 방법을 알아요.
Korean food 한국 음식 cook 요리하다
04
I know how to fix it.
그거 고치는 법 알아요.
I know how to fix it because I watched it on YouTube.
그거 고치는 법 알아요. 유튜브에서 봤거든요.
I know how to fix it because I watched it on YouTube last weekend.
그거 고치는 법 알아요. 지난 주말에 유튜브에서 봤거든요.
fix 고치다, 수리하다 because ~때문에 last weekend 지난 주말에
05
I know how to handle it.
저 그거 어떻게 처리하는지 알아요.
I know how to handle it by myself.
저 혼자서 그거 어떻게 처리하는지 알아요.
I know how to handle it by myself without any help.
저 혼자서 그거 어떻게 처리하는지 알아요. 도움 없이도요.
handle 다루다, 처리하다 by myself 혼자서 without ~없이

06
I know how to get there.
나는 가는 법을 알아요.
I know how to get there on time.
저는 그곳에 제시간에 가는 법을 알아요.
I know how to get there on time even if the traffic is heavy.
저는 교통이 막혀도 그곳에 제시간에 가는 법을 알아요.
get there 그곳에 도착하다 on time 제시간에 even if 비록 ~일지라도
07
I know how to solve it.
어떻게 해결하는지 알아요.
I know how to solve it when my computer is slow.
컴퓨터가 느려질 때 어떻게 해결하는지 알아요.
I know how to solve it when my computer is slow because my friend showed me some tips.
컴퓨터가 느려질 때 어떻게 해결하는지 알아요. 제 친구가 몇 가지 팁을 알려줬거든요.
solve 해결하다 when ~할 때 show (someone) tips 팁을 알려주다
08
I know how to make it.
나는 만들 줄 알아요.
I know how to make it by hand.
손으로 만드는 법을 알아요.
I know how to make it by hand, but it takes a lot of time.
손으로 만드는 법을 알아요, 그런데 시간이 많이 걸려요.
by hand 손으로 but 하지만 take time 시간이 걸리다
09
I know how to use this app.
이 앱을 어떻게 사용하는지 알아요.
I know how to use this app to edit photos.
이 앱을 어떻게 사용하는지 알아요. 사진을 편집할 수 있어요.
I know how to use this app to edit photos and share them with my friends.
이 앱을 어떻게 사용하는지 알아요. 사진을 편집할 수 있고 친구들과 공유할 수도 있어요.
edit 편집하다 share 공유하다
10
I know how to ski.
저는 스키 타는 법을 알아요.
I know how to ski, but I don't know how to snowboard.
저는 스키 타는 법을 알아요. 하지만 스노보드는 못 타요.
I know how to ski, but I don't know how to snowboard because it's too hard.
저는 스키 타는 법은 알아요. 하지만 스노보드는 너무 어려워서 못 타요.
ski 스키를 타다 snowboard 스노보드를 타다 too hard 너무 어려운
