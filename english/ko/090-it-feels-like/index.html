Grammar Point
It feels like는 '~인 것 같은 느낌이 든다'는 의미로, 감각이나 감정적 인상을 표현할 때 사용해요.
like 뒤에 명사나 주어 + 동사 형태의 절을 모두 쓸 수 있어요.
I think가 논리적 판단이라면, It feels like는 몸이나 감정으로 느끼는 주관적 감각에 가까워요.

01
It feels like summer.
여름 같아요.
It feels like summer even though it's only May.
5월인데 벌써 여름 같아요.
It feels like summer even though it's only May and everyone's wearing short sleeves.
5월인데 벌써 여름 같아요. 모두 반팔을 입고 있어요.
even though 비록 ~이지만 short sleeves 반팔
02
It feels like home.
집처럼 편안하게 느껴져요.
It feels like home at my grandma's place.
할머니 댁은 집처럼 편안하게 느껴져요.
It feels like home at my grandma's place that I visit every weekend.
주말마다 방문하는 할머니 댁은 집처럼 편안하게 느껴져요.
grandma's place 할머니 댁 every weekend 주말마다
03
It feels like yesterday.
어제 일 같아요.
It feels like yesterday when I started this job.
이 일을 시작한 게 엊그제 같아요.
It feels like yesterday when I started this job, but it's already been three years.
이 일을 시작한 게 엊그제 같은데 벌써 3년이 지났어요.
already been 벌써 ~이 되었다 three years 3년
04
It feels like flying.
날아가는 것처럼 느껴져요.
It feels like flying when I'm skiing.
스키를 탈 때 날아가는 것처럼 느껴져요.
It feels like flying when I'm skiing fast down the mountain.
산에서 빠르게 스키를 탈 때 날아가는 것처럼 느껴져요.
fast down ~을 빠르게 내려오며 down the mountain 산 아래로
05
It feels like a dream.
꿈만 같아요.
It feels like a dream to be here.
여기 있는 게 꿈만 같아요.
It feels like a dream to be here because everything turned out perfectly.
여기 있는 게 꿈만 같아요. 모든 게 완벽하게 이루어졌거든요.
turn out 결과가 ~이 되다 perfectly 완벽하게

06
It feels like I have a cold.
감기에 걸린 것 같아요.
It feels like I have a cold, and I've felt this way since this morning.
아침부터 감기에 걸린 것 같아요.
It feels like I have a cold, and I've felt this way since this morning, so I'm going to the pharmacy today.
아침부터 감기에 걸린 것 같아서 오늘 약국에 갈 거예요.
felt this way 이런 느낌이 들다 pharmacy 약국
07
It feels familiar.
낯익은 것 같아요.
It feels familiar here.
이곳이 낯익은 것 같아요.
It feels familiar here, like I've been here before.
예전에 와본 것처럼 이곳이 낯익은 것 같아요.
familiar 낯익은, 익숙한 like I've been 와본 것처럼
08
It feels like it's my first time.
처음인 것 같아요.
It feels like it's my first time at this restaurant.
이 레스토랑에 와본 게 처음인 것 같아요.
It feels like it's my first time at this restaurant with such a quiet atmosphere.
이렇게 조용한 분위기의 레스토랑에 와보는 게 처음인 것 같아요.
atmosphere 분위기 quiet 조용한
09
It feels like it's going to rain.
비가 올 것 같아요.
It feels like it's going to rain today.
오늘 비가 올 것 같아요.
It feels like it's going to rain today because of the dark clouds.
구름이 많아서 오늘 비가 올 것 같아요.
because of ~ 때문에 dark clouds 먹구름
10
It feels like time is going by so fast.
시간이 정말 빨리 가는 것 같아요.
It feels like time is going by so fast. It's already evening.
시간이 정말 빨리 가는 것 같아요. 벌써 저녁이네요.
It feels like time is going by so fast. It's already evening, and today feels so short.
시간이 정말 빨리 가는 것 같아요. 벌써 저녁이네요. 오늘 하루가 정말 짧게 느껴져요.
going by 흘러가다 already 벌써, 이미
