패턴영어 009  ·  오늘의 핵심 패턴
Please
"~해주세요"

짧은 문장에 살을 붙여가는 꼬리물기 방식으로 자신의 실력에 맞게 단계별로 학습하세요.

짧게 말하기 · 초급 + 확장해서 말하기 · 중급 + 더 추가해서 말하기 · 고급

본문 하단의 동영상 강의를 활용하시면 학습 효과가 훨씬 높아집니다.

패턴 009

Please

"~해주세요"
영상 강의
클릭
또는
스캔
Grammar Point
Please는 동사 앞에 붙여 정중한 요청이나 부탁을 표현하는 가장 기본적인 방법이에요.
명령문의 직접적인 느낌을 부드럽게 만들어주며, 상대방에 대한 예의와 배려를 담고 있어요.
격식체와 비격식체 모두에서 자연스럽게 사용할 수 있어요.
#
짧게 말하기(초급)  +  확장해서 말하기(중급)  +  더 추가해서 말하기(고급)
01
Please help.
도와주세요.
Please help me set up the TV.
티비 설치하는 거 좀 도와주세요.
Please help me set up the TV because the remote isn't working properly.
티비 설치하는 거 좀 도와주세요. 리모컨이 제대로 작동을 안 해서요.
set up 설치하다, 설정하다 properly 제대로, 올바르게
02
Please wait.
기다려 주세요.
Please wait at the front desk.
안내 데스크에서 기다려 주세요.
Please wait at the front desk while I check your documents.
안내 데스크에서 기다려 주세요. 제가 서류를 확인하는 동안요.
front desk 안내 데스크, 프런트 document 서류, 문서
03
Please sit.
앉으세요.
Please sit on the couch and relax.
거실 소파에 앉아서 편히 쉬세요.
Please sit on the couch and relax while I prepare some tea for you.
차를 준비하는 동안 소파에 앉아서 편히 쉬세요.
relax 편히 쉬다, 긴장을 풀다 prepare 준비하다
04
Please call.
전화 주세요.
Please call me back when you get home.
집에 도착하면 저한테 전화 주세요.
Please call me back when you get home, because I need to discuss something important.
집에 도착하면 저한테 전화 주세요, 중요한 얘기가 있어서요.
call back 다시 전화하다 discuss 논의하다, 이야기하다
05
Please listen.
잘 들어주세요.
Please listen carefully.
제가 하는 말을 주의 깊게 들어주세요.
Please listen carefully to the important instructions.
제가 하는 말을 주의 깊게 들어주세요, 중요한 지시 사항입니다.
carefully 주의 깊게, 신중하게 instructions 지시 사항, 안내
더 학습해서 기억에 남기기
패턴 009 — 추가 예문으로 확실하게 내 것 만들기
Please
06
Please tell.
말해 주세요.
Please tell me about your volunteer work this weekend.
이번 주말에 하는 봉사 활동에 대해 말씀해 주세요.
Please tell me about your volunteer work this weekend, so that I can help you prepare.
이번 주말에 하는 봉사 활동에 대해 말씀해 주세요, 제가 준비하는 걸 도와드릴 수 있게요.
volunteer work 봉사 활동 so that ~할 수 있도록
07
Please stop.
멈추세요.
Please stop making that loud noise.
그 시끄러운 소리 좀 그만 내주세요.
Please stop making that loud noise because I am trying to focus.
집중하려고 하니 그 시끄러운 소리 좀 그만 내주세요
focus 집중하다 because ~때문에
08
Please come.
와 주세요.
Please come if you are available.
시간이 되시면 와 주세요.
Please come if you are available to discuss the project details tomorrow morning.
내일 아침 프로젝트 세부 사항을 논의하기 위해 시간이 되시면 와 주세요.
available 시간이 되는, 가능한 details 세부 사항
09
Please give.
주세요.
Please give me the movie ticket.
영화표 좀 주세요.
Please give me the movie ticket before the show starts.
상영 시작 전에 영화표 좀 주세요.
before ~하기 전에 show 상영, 공연
10
Please be quiet.
조용히 해주세요.
Please be quiet in the library.
도서관에서 조용히 해 주세요.
Please be quiet in the library because other people are studying.
도서관에서 조용히 해 주세요. 다른 사람들이 공부하고 있거든요.
quiet 조용한 because ~때문에
