I think 문법 포인트 — Grammar Point

Grammar Point
'I think'는 자신의 의견이나 추측을 부드럽게 표현할 때 사용하는 패턴이에요.
단정적으로 말하는 대신 불확실함이나 겸손함을 나타내며, 상대방의 의견을 존중하는 뉘앙스를 담고 있어요.
'I think + 주어 + 동사' 형태로 뒤에 어떤 문장이든 자연스럽게 연결할 수 있어요.

저도 그렇게 생각해요, 근데 완전히 확신하는 건 아니에요. 왜냐하면 상황이 매일 계속 바뀌거든요.
completely 완전히situation 상황
02
I think it is possible.
나는 가능하다고 생각해요.
I think it is possible to exercise every morning.
매일 아침 운동하는 게 가능하다고 생각해요.
I think it is possible to exercise every morning if I wake up earlier.
매일 아침 운동하는 게 가능하다고 생각해요. 만약 더 일찍 일어난다면요.
possible 가능한wake up 일어나다
03
I think that's right.
저는 그것이 맞다고 생각해요.
I think that's right, based on what I've seen.
저는 제가 본 것을 바탕으로 그것이 맞다고 생각해요.
I think that's right, based on what I've seen, because the results show it very clearly.
저는 제가 본 것을 바탕으로 그것이 맞다고 생각해요, 결과가 매우 명확하게 보여주고 있거든요.
based on ~을 바탕으로clearly 명확하게
04

저는 그것이 옳다고 생각해요.
I think that's correct, based on the latest report.
저는 최신 보고서를 보면 그것이 옳다고 생각해요.
I think that's correct, based on the latest report, which was quite convincing.
저는 최신 보고서를 보면 그것이 옳다고 생각해요, 꽤 설득력 있는 내용이었거든요.

05
I think it's a good idea.
나는 좋은 생각이라고 생각해요.
I think it's a good idea to use the subway.
지하철을 이용하는 게 좋은 생각인 것 같아요.
I think it's a good idea to use the subway since traffic is really bad downtown.
지하철을 이용하는 게 좋은 생각인 것 같아요, 시내 교통이 정말 안 좋거든요.

저는 그가 요즘 프로젝트 때문에 바쁘다고 생각해요, 그래서 방해하지 않는 것이 좋겠어요.

07

I think this is better with the new design.

I think this is better with the new design to attract more customers.
저는 더 많은 고객을 유치하기 위해 새로운 디자인으로 이것이 더 낫다고 생각합니다.
attract 유치하다design 디자인
08
I think we are lost.

I think we are lost in this big building because all the hallways look the same.
복도가 다 똑같이 생겨서 이 큰 건물 안에서 길을 잃은 것 같아요.

09
I think it will take time.
나는 시간이 걸릴 거라고 생각해요.
I think it will take time to finish the report.
보고서를 끝내는 데 시간이 걸릴 것 같아요.
I think it will take time to finish the report because the data isn't ready yet.
보고서를 끝내는 데 시간이 걸릴 것 같아요. 아직 데이터가 준비되지 않았거든요.
take time 시간이 걸리다ready 준비된

I think it is important.

I think it is important for everyone to understand the new policy quickly.
